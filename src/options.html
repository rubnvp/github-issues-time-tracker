Picture-in-Picture

Daily focus goal

While focusing, the bar is green with two light-green sweeps moving to the right. The percentage shows two decimal places based on recorded focus time. When paused, green means on pace or ahead; amber means behind. The white mark shows the expected progress, which pauses during breaks. Without a work schedule, only goal progress is shown. Reduced-motion preferences disable the animation.

Work schedule

Set local work hours for each day, using multiple intervals for breaks. PiP shows work intervals in color and breaks in dark, with a marker for the current time. The percentage counts only scheduled work hours and pauses during gaps, independently of time spent focusing.
