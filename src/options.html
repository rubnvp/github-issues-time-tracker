Settings

Customize how GitHub Issues Time Tracker behaves.

Usage level

Choose how much support you want. Higher levels include the features below them.

Changing levels preserves your settings and recorded time. Options from higher levels are inactive until you return to them. Automatic PiP and reminders remain optional.

Picture-in-Picture

Daily focus goal

While focusing, the bar is green with two light-green sweeps moving to the right. The percentage shows two decimal places based on recorded focus time. Reduced-motion preferences disable the animation.

When paused, green means on pace or ahead; amber means behind. The white mark shows expected progress, which pauses during breaks. Without a work schedule, only goal progress is shown.

Focus reminders

Work schedule

Set local work hours for each day, using multiple intervals for breaks. PiP shows work intervals in color and breaks in dark, with a marker for the current time. The percentage counts only scheduled work hours and pauses during gaps, independently of time spent focusing.
